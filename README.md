Telegram Summary Bot
Telegram‑бот, который делает ежедневное саммари переписки в чате и считает топ‑3 самых активных участников.
Поддерживает загрузку JSON‑экспорта чата и интеграцию с Cerebras Cloud (Llama 3.1).

Возможности
Принимает JSON‑файл экспорта чата Telegram (формат стандартного экспорта).

Извлекает:

все текстовые сообщения за день;

авторов и их активность.

Генерирует красивый отчёт в стиле ежедневного дайджеста:

общее краткое резюме дня;

3–5 ключевых тем с короткими описаниями;

блок открытых вопросов/проблем;

топ‑3 «клавиатурных бойцов».

Работает с Cerebras Cloud API
